# Portfólio de Gustavo Fernandes Aguilar do Nascimento

Site pessoal estático feito com HTML, CSS e JavaScript. Abra index.html no navegador para visualizar.

## Arquivos

- index.html: conteúdo do portfólio, projetos, formação, conhecimentos e contatos.
- styles.css: identidade visual e layout responsivo.
- script.js: menu mobile e atualização automática do ano.

## Conteúdo incluído

Os dados foram organizados a partir do currículo enviado. Os projetos do GitHub e os certificados estão vinculados aos endereços informados no documento. Os certificados aparecem como links, sem imagens.

Para atualizar o conteúdo, edite os textos e links correspondentes no index.html. A fonte tipográfica é carregada do Google Fonts quando há conexão com a internet; sem conexão, o navegador usa fontes alternativas.

## Imagens dos projetos

A pasta images contém prévias vetoriais feitas a partir das interfaces e do comportamento descritos nos repositórios, para mostrar o aspecto dos projetos sem depender de imagens remotas.

## Animações

Habilidades e contatos aparecem com uma transição suave ao entrar na tela. As interações de hover são discretas e respeitam a preferência de movimento reduzido do navegador.

A área de contato tem ícones clicáveis para abrir uma nova mensagem no Gmail e o perfil do Instagram.

## Publicação

O site é publicado pelo GitHub Pages. Alterações enviadas para a branch `main` iniciam uma nova publicação automaticamente.

Endereço do site: https://gustav263.github.io/portfolio-gustavo/
